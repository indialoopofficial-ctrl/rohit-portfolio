ROHIT PORTFOLIO - INSTALL

1) Copy the zip to your phone's Download folder.
2) In Termux:
   cd ~/rohit-portfolio
   cp -r src src-backup
3) Extract the downloaded package and copy its src folder into ~/rohit-portfolio.
4) Run:
   cd ~/rohit-portfolio
   npm run dev -- --host 0.0.0.0
5) Open http://localhost:5173/

The portfolio includes:
- Premium responsive dark design
- Hero / About / Projects / Services / Contact sections
- GoldCalc India project link
- Email contact button
- WhatsApp button
- Mobile responsive layout
